## 各层升级明细

### 统计层 v3
- PREV 槽（前事件进程类别）→ 跨事件序列依赖
- PREV 类别压缩（191 → 17 语义类别）→ 词表 505→333
- EWMA 自适应 baseline → 动态阈值（非固定 3.0）
- 效果：lateral 0→100%, privesc 1→33%

### 语义层 v5 + 后置规则
- 对比学习 + 分类头（6 类行为意图）
- 后置规则过滤：sudo/systemd/modprobe/良性命令白名单
- 条件白名单：find/chmod 在非 SUID 操作时是良性
- focal loss (γ=2.0) 训练
- 效果：FPR 8.4%→3.1%（独立），0.5%（融合后）

### 时序层
- CV 分析器（CV<1.5 = 机器节奏）
- FFT 周期检测（SNR>5 = C2 信标，60s 精确检出）
- 多尺度 CV（1min/5min/15min）
- UID 过滤（系统进程不算时序异常）
- 连续 3 次才报（避免单次噪声）

### 自适应层
- 变体容忍（允许 1-3 个噪声命令插入）
- 自动模式发现（从 patterns.jsonl 加载序列做模糊匹配）
- 7/7 合成测试通过

### 语义嵌入
- mini-encoder（char-CNN）训练 209 token 描述
- 聚类比 42-48x（file_read / net_tool）
- α=0.3 可选注入（默认不用，等更多数据后启用）

### 六网融合
- P0：统计+语义交叉确认 → 自动处置
- P1：自适应层命中已知攻击
- P2：语义层独判
- P3：统计层独判
- P4：时序连续异常 / FFT 周期
- P5：弱信号

## 模型清单
